# Termodinámica Aplicada: Calculador de Gas Ideal

Script en Python desarrollado para modelar y resolver el comportamiento de los gases ideales bajo los principios de la termodinámica clásica.

## Fundamento Teórico
El sistema implementa la ecuación de estado de los gases ideales:
$$P = \frac{n R T}{V}$$

Donde:
- $P$: Presión resultante ($\text{atm}$)
- $n$: Número de moles ($\text{mol}$)
- $R$: Constante universal de los gases ideales ($0.0821 \text{ L}\cdot\text{atm} / \text{K}\cdot\text{mol}$)
- $T$: Temperatura absoluta ($K$)
- $V$: Volumen del sistema ($L$)

## Requisitos del Entorno
- Python 3.x instalado.
